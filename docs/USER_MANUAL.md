## Getting Started

### System Requirements

#### For Web Access
- **Browser**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Internet Connection**: Stable broadband (minimum 512 Kbps)
- **Device**: Desktop, laptop, or tablet
- **Screen Resolution**: Minimum 1024x768

#### For Mobile Access
- **Operating System**: Android 8.0+ or iOS 12.0+
- **Storage**: Minimum 100MB free space
- **Permissions**: Camera, location, storage access

### Account Registration

#### Beneficiary Registration

1. **Access Registration Page**
   - Visit the beneficiary portal URL
   - Click "Register New Account"

2. **Enter Personal Details**
   ```
   Full Name: [Your full name]
   Phone Number: [10-digit mobile number]
   Aadhaar Number: [12-digit Aadhaar number]
   Date of Birth: [DD/MM/YYYY]
   ```

3. **Verify Identity**
   - OTP verification on registered phone
   - Aadhaar biometric verification (optional)
   - Email verification (if provided)

4. **Set Security**
   - Create strong password (8+ characters)
   - Set up PIN for mobile app
   - Enable biometric authentication

#### Officer Registration

1. **Receive Invitation**
   - Administrator sends invitation email
   - Contains temporary login credentials

2. **First Login**
   - Use temporary credentials
   - Change password immediately
   - Complete profile setup

3. **Role Assignment**
   - Administrator assigns roles and permissions
   - Configure district assignments
   - Set up notification preferences

### Login Process

#### Web Login

1. **Navigate to Login Page**
   - Enter the portal URL
   - Click "Login"

2. **Enter Credentials**
   ```
   Username: [Email/Phone/Aadhaar]
   Password: [Your password]
   ```

3. **Two-Factor Authentication**
   - Enter OTP sent to registered device
   - Or use authenticator app

4. **Dashboard Access**
   - Redirected to appropriate dashboard
   - Based on user role and permissions

#### Mobile Login

1. **Open Application**
   - Launch Nyantara DBT app
   - Tap "Login"

2. **Biometric Login**
   - Use fingerprint/face recognition
   - Or enter PIN

3. **OTP Verification**
   - Enter OTP for additional security
   - For first login or high-risk operations

### Applying for Benefits

#### Step 1: Select Benefit Type

1. **Navigate to Applications**
   - Click "New Application" from dashboard
   - Or select from menu: Applications → New Application

2. **Choose Act Type**
   ```
   Available Options:
   • PoA (Pradhan Mantri Awas Yojana)
   • MGNREGA (Mahatma Gandhi National Rural Employment Guarantee Act)
   • PDS (Public Distribution System)
   • Other Government Schemes
   ```

3. **Check Eligibility**
   - System automatically checks eligibility
   - Displays requirements and criteria
   - Shows estimated processing time

#### Step 2: Fill Application Form

1. **Personal Information**
   ```
   Required Fields:
   • Full Name
   • Date of Birth
   • Gender
   • Marital Status
   • Address Details
   • Income Category
   ```

2. **Bank Account Details**
   ```
   Required Information:
   • Account Holder Name
   • Account Number
   • IFSC Code
   • Bank Name
   • Branch Name
   ```

3. **Supporting Documents**
   ```
   Mandatory Documents:
   • Aadhaar Card
   • Income Certificate
   • Address Proof
   • Bank Passbook

   Optional Documents:
   • Caste Certificate
   • Disability Certificate
   • Ration Card
   ```

#### Step 3: Review and Submit

1. **Review Application**
   - Check all entered information
   - Verify document uploads
   - Confirm bank details

2. **Submit Application**
   - Click "Submit Application"
   - Receive confirmation with application ID
   - Get OTP verification

3. **Track Progress**
   - Application status updates in real-time
   - Email/SMS notifications for status changes
   - Estimated processing timeline

1. **Access Grievance Portal**
   - Dashboard → Support → File Grievance

2. **Select Grievance Category**
   ```
   Categories:
   • Payment Related
   • Application Status
   • Document Issues
   • Profile Updates
   • Technical Issues
   • Other
   ```

3. **Provide Details**
   ```
   Required Information:
   • Grievance Title
   • Detailed Description
   • Related Application ID (if applicable)

   ```

4. **Submit and Track**
   - Submit grievance with attachments
   - Receive grievance reference number

```

Priority Levels:
• Low: General inquiries (7-10 days)
• Medium: Standard issues (3-7 days)
• High: Urgent matters (1-3 days)
```

## Troubleshooting

### Common Issues

#### Login Problems

**Issue:** Cannot login to account
```
Solutions:
1. Check internet connection
2. Verify username/password
3. Clear browser cache/cookies
4. Try different browser
5. Reset password if forgotten
6. Contact support if persistent
```

**Issue:** OTP not received
```
Solutions:
1. Check SMS inbox/spam folder
2. Verify phone number in profile
3. Wait 5 minutes for retry
4. Check network signal
5. Contact support for alternative verification
```

#### Application Issues

**Issue:** Application submission failed
```
Solutions:
1. Check all mandatory fields filled
2. Verify document uploads
3. Ensure file sizes within limits
4. Check internet connection
5. Try resubmission after fixes
6. Contact support for technical issues
```

**Issue:** Documents not uploading
```
Solutions:
1. Check file format (PDF/JPG/PNG)
2. Verify file size (max 5MB)
3. Ensure stable internet connection
4. Try different browser/device
5. Clear browser cache
6. Contact support for assistance
```

#### Payment Issues

**Issue:** Payment not received
```
Solutions:
1. Check payment status in portal
2. Verify bank account details
3. Contact bank for transaction status
4. Check for payment reversals
5. File grievance if delayed
6. Contact support for investigation
```

#### Common Error Codes

| Error Code | Description | Solution |
